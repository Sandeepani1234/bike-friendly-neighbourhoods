# Bike-Friendly Neighbourhoods — image-refreshed prototype

This ZIP contains a responsive standalone prototype with refreshed professional Nordic-style imagery, registration modal, 14-question assessment, score summary, action-plan generation, browser-local draft saving, and a demo reviewer list.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
Upload the contents of this folder to the root of your `bike-friendly-neighbourhoods` repository and commit the changes. Keep the `images` folder alongside `index.html`, `styles.css`, and `app.js`.

## Important demo limitations
Registration, drafts, and review submissions are stored only in the current browser using localStorage. There is no server, real authentication, shared database, or live Energicentrum connection. This ZIP is a reconstructed standalone prototype because the previously referenced ZIP was not available in the working folder; it is not a pixel-for-pixel update of your original repository source.
